# Godnotic artwork

`godnotic-banner.png` and `godnotic-icon.png` were made with the built-in image
creation tool using the existing eagle motif as a reference. PNG exports retain
transparency; sized icons are package exports of the same master.

Banner brief: exact word GODNOTIC, recognizable eagle inside the first O,
blue metallic lettering and orange rim, transparent background, no subtitle,
version or Touch label. Icon brief: complete blue O surrounding the same orange
eagle, legible at launcher size, transparent outside the ring, no text.

The menu texture uses the same banner in the original menu layer's upper-left
logo region; remaining pixels are transparent. Original upstream license notices
are retained in the source repositories.
