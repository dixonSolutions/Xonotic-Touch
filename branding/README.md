# Godnotic artwork

Everything here is generated by `scripts/gen-branding.py`; do not edit the PNGs by hand.

```sh
python3 scripts/gen-branding.py
```

- **Icon** (`godnotic-icon.svg`, `godnotic-icon*.png`, `web/icon-*.png`): the Xonotic
  phoenix emblem from `engine/misc/logos/xonotic_icon.svg`, unchanged apart from a
  little padding so launchers do not clip its glow.
- **Banner** (`godnotic-banner.png`, `web/godnotic-banner.png`,
  `touch/gfx/xonotic_logo.png`): GODNOTIC set in Xolonium, the game's own typeface,
  with the same emblem as the first O. No subtitle and no version.
- **Menu layer** (`godnotic-menu-layer.png`,
  `touch/gfx/menu/luma/touch_background_l2.tga`): the banner in the upper left of an
  otherwise transparent 2560x2048 sheet, drawn over the menu background.
